# Решись Авиа

Веб-приложение для оценки спроса и продаж при заданной цене. Прогноз доступен для пяти маршрутов из Москвы с 1 июня по 1 июля 2026 года. Регистрация и вход работают через локальные аккаунты. Для просмотра прогноза вход не требуется.

## Запуск

Python 3.10 или новее.

```sh
python -m pip install -r requirements.txt
python -m flask --app app run
```

Откройте [localhost:5000](http://localhost:5000).

## Расчёт

Flask читает `data/my_forecast.csv` из ML-блокнота и `data/routes.csv` из материалов задачи. Для каждого квантиля из спроса при базовой цене вычитается разница цен, умноженная на чувствительность к цене. Спрос ограничивается снизу нулём, продажи ограничиваются вместимостью. Карточки показывают прогноз по медиане. На графике показан спрос до ограничения вместимостью.

Пример: `GET /api/forecast?route=MOW-AER&date=2026-06-12&price=9000`.

## Timeweb

Используется [виртуальный хостинг Flask](https://timeweb.com/ru/docs/virtualnyj-hosting/prilozheniya-i-frejmvorki/flask/) с Python 3.10 и WSGI. Корень сайта должен указывать на `public_html`. Остальные файлы проекта лежат на один уровень выше.

Из корня проекта на сервере:

```sh
python3.10 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
chmod 755 public_html/index.wsgi
```

Включите HTTPS для домена. `index.wsgi` подключает окружение и устанавливает флаг Secure для cookie. База аккаунтов создаётся в `instance/` при первом запуске. Пользователю веб-сервера нужна запись в эту директорию.
